# Busca Coletiva

Site estático para apresentação da Busca Coletiva.

## GitHub Pages

Em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)` e Save.

Endereço previsto: https://felipe-brosa.github.io/busca-coletiva/

Cadastro direto: https://felipe-brosa.github.io/busca-coletiva/#cadastrar

## Funcionamento desta prévia

A busca usa dados fictícios. Os cadastros e imagens permanecem apenas na memória da página e são descartados ao recarregar. Não há envio real, integração com planilha ou moderação. A validação obrigatória está temporariamente desativada para revisão do layout. O limite de imagem é 1 MB.

## Arquivos

O site fica na raiz, com módulos JavaScript, CSS e imagens/fontes em `assets/`. As rotas usam fragmentos (`#buscar`, `#cadastrar`), compatíveis com GitHub Pages. Não há dependências nem etapa de compilação.
